# C++ Largest of Two Numbers

## About
This program takes two numbers as input and determines which number is larger. It also checks whether both numbers are equal.

## Concepts Used
- Variables and data types
- User input and output (`cin`, `cout`)
- If-else statements
- Relational operators (`>`, `<`)
